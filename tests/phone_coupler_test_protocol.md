# Phone Coupler Test Protocol

Status: initial protocol

## Objective

Find whether a passive coupler improves phone reception and whether the improvement is repeatable.

## Variables

- phone model
- phone case on or off
- coupler geometry
- phone-to-coupler gap
- vertical offset
- horizontal offset
- rotation
- network band
- antenna and coax used

## Suggested Sweep

Test gaps from about 2 mm to 30 mm. Record indexed positions so the best result can be repeated.

## Measurements

- baseline phone signal
- phone signal at each position
- RSRP
- RSRQ
- SINR
- app success
- notes on handling sensitivity
