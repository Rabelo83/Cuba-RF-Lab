# Data Templates

Status: active

Use templates in this folder for consistent field and lab data collection.

Current templates:

- `blackout_measurement.csv`: field measurements during normal and blackout conditions.
- `antenna_candidate_comparison.csv`: calculated or simulated antenna candidate comparison data.
- `production_cost_estimate.csv`: cost estimate template for public build packages.

Use the production-cost template before moving any design toward public build instructions.
