# 1800 MHz Yagi

Status: CONCEPT

## Goal

Investigate a directional antenna optimized near 1800 MHz for LTE Band 3 performance, if local measurements confirm that LTE Band 3 remains available during useful outage windows.

## Design Requirements

- Do not invent gain.
- Account for element diameter and spacing.
- Simulate impedance and pattern.
- Document feed and balun arrangement.
- Include connector and coax loss in the system budget.
- Label the design as not field validated until tested.
