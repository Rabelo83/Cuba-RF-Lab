# Approved Blueprints

Status: empty

No approved blueprints exist yet.

Files may be added here only after calculations, simulation, review notes, and approval. If not field tested, the design must clearly state `NOT FIELD VALIDATED`.

Approved public designs must also include a costed bill of materials, local substitute options, required tools, and repair guidance. A high-performance design is not approved if it is too expensive or impractical for Cuban users.
