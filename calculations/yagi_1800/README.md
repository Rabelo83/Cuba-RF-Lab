# 1800 MHz Yagi Calculations

Status: planned

This folder will hold calculations for a directional antenna optimized near LTE Band 3 around 1800 MHz, if local measurements confirm that band remains useful.

Calculations should include whether the smaller size and lower material cost are worth the risk that 1800 MHz service may be weaker or unavailable during blackouts.

- `../preliminary_antenna_geometry.md`
- `../../data/processed/antenna_candidate_first_pass.csv`
