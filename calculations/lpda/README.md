# LPDA Calculations

Status: planned

This folder will hold log-periodic dipole array calculations.

Important: early conceptual values such as tau around 0.86 and sigma around 0.16 are not approved build data. They may be used as a starting point for calculation experiments only.

LPDA calculations must include comparison against simpler 900 MHz and 1800 MHz Yagis, dual-band concepts, and the phone-at-RF-location architecture. Do not advance an LPDA unless its broadband benefit justifies the extra feed, tolerance, and fabrication complexity.
